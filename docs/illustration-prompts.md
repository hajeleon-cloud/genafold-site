# Illustration prompts — ready to paste

Copy any single block below and paste it directly into an AI image tool
(ChatGPT/DALL·E, Midjourney, etc.). Each one is complete and self-contained —
nothing to fill in or combine.

---

## 1. DNA / Bioinformatics

```
Create a clean, modern isometric 3D vector illustration of a DNA
double-helix strand, rendered as smooth ribbon-like geometry with
glowing rungs connecting the two strands. The helix rises up from a
small floating rounded platform. Soft gradients, subtle drop shadows,
gentle glow around the strand as if lit from within. A faint circuit-
board / grid-line texture in the background, very subtle. Color palette:
teal (#0EA5AC) and deep navy-blue (#0A1F3D) only, on a white background.
No text, no logos, no watermarks. Square 1:1 aspect ratio, centered
composition with breathing room around the edges. Crisp vector-style
edges, not photorealistic or sketchy.
```
